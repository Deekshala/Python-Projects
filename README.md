PYTHON BASIC PROJECTS 🐍

## About This Repository ##
This repository contains a collection of beginner-friendly Python projects created to strengthen my programming fundamentals, logical thinking, and problem-solving skills. Each project demonstrates practical applications of Python concepts and helps me gain hands-on coding experience.

## Projects Included ##

1. **Dice Rolling Game** – Simulates dice rolls using random number generation.
2. **Number Guessing Game** – Allows users to guess a randomly generated number.
3. **Pig Dice Game** – A dice game where players roll to accumulate points while managing the risk of losing their turn's score.
4. **QR Code Generator** – Generates QR codes for text or URLs using a Python library.
5. **Quiz Game** – Presents questions, checks answers, and calculates the score.
6. **Rock Paper Scissors Game** – Lets users play the classic game against the computer.
7. **Tic-Tac-Toe Game** – Implements the classic two-player game using Python logic.
8. **To-Do List App** – Allows users to add, view, and remove tasks.
